## 实现差异

名义状态的积分方式不同。KF-GINS 使用导航系双样本机械编排，补偿圆锥、转动和划桨，并考虑地球自转与正常重力。Solà 系列代码多在局部笛卡尔系用中值积分，适合短时机器人定位，不处理地球模型和厘米级大地坐标。

误差定义不同。KF-GINS 的姿态误差是导航系 $\phi$ 角，位置误差在经纬高附近用导航系米制误差。Solà 系列用四元数右乘小旋转。FAST-LIO 用 IKFoM 把旋转放在 $SO(3)$、重力放在 $S^2$，协方差在切空间，迭代更新时会重新线性化。

量测不同。KF-GINS 只有 GNSS 位置更新。Matlab 版增加速度更新，并留出车体系速度更新。`imu_x_fusion` 可以把六自由度位姿当松组合量测，轮速计和雷达在其 README 中仍是未完成项。FAST-LIO 的主量测是点到平面。多传感器分支在此之外增加 GNSS 位置和轮速，并估计轮子外参与刻度因数。

运行形态不同。前两个仓库是离线文件输入，Windows 上可以编译或用 Matlab 运行。后六个仓库依赖 ROS 或 ROS2，上游文档以 Ubuntu 为准。

## 不要混用的输出

KF-GINS 的导航结果是 GNSS 周、周内秒、经纬高、北东地速度和滚转俯仰航向。FAST-LIO 输出的是局部地图系下的高频里程计。比较轨迹前必须统一时间系统和坐标，不能把两种文本直接相减。

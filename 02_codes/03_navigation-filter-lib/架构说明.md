# navigation-filter-lib 架构说明

上游：https://github.com/peanut-nav/navigation-filter-lib

头文件为主的捷联惯导加 GNSS 误差状态滤波库，用同一套仿真数据比较线性 KF、EKF 和 UKF，并可选 RTS 平滑。默认分支为 master。状态为 15 维：位置、速度、姿态、陀螺零偏、加计零偏。重力使用 Somigliana 模型。数据是固定随机种子的仿真 IMU 与 GPS，不是实测 RTK 或底盘。

## 框架

预测由捷联机械编排完成。KF 使用线性误差模型；EKF 用 RK4 传播非线性名义状态，并用离散雅可比传播协方差；UKF 在误差状态上使用无迹变换。RTS 从轨迹末端反向平滑。

可执行目标：

| 目标 | 内容 |
| --- | --- |
| `IntegratedNavigationKF` | 15 维误差状态线性卡尔曼滤波加 RTS |
| `IntegratedNavigationEKF` | 15 维误差状态扩展卡尔曼滤波加 RTS |
| `IntegratedNavigationUKF` | 15 维误差状态无迹卡尔曼滤波加 RTS |

Python 脚本 `scripts/nav_visualizer.py` 画结果。

## 运行环境

- CMake 3.15 及以上，C++ 编译器，Eigen3。
- Windows 可用 Visual Studio 生成工程。Eigen 若未安装，使用 vcpkg 或把 `EIGEN3_INCLUDE_DIR` 指到本地解压目录。
- Python 3 仅用于画图。

这个仓库用来理解“误差状态 KF、EKF、UKF 差在哪里”，不能直接验证 RTK 与底盘。

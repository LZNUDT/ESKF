# KF-GINS-Matlab 架构说明

上游：https://github.com/i2Nav-WHU/KF-GINS-Matlab

KF-GINS 的 Matlab 教学版，便于单步调试。除复现 C++ 版的 GNSS 位置更新外，增加了 GNSS 速度更新，以及里程计/非完整约束更新框架。上游说明：ODO/NHC 量测更新没有完整实现，里程计标度因数误差没有加入状态。

## 框架

入口 `kf_gins.m` 按 IMU 时间推进，并在 GNSS 或里程计时刻插值。

| 文件 | 作用 |
| --- | --- |
| `Initialize.m` | 初始名义状态与协方差 |
| `InsMech.m` | 捷联机械编排 |
| `InsPropagate.m` | 误差状态预测与协方差传播 |
| `GNSSUpdate.m` | GNSS 位置、速度更新 |
| `GetOdoVel.m` | 由原始里程计得到速度 |
| `ODONHCUpdate.m` | 车体系速度更新框架 |
| `ErrorFeedback.m` | 误差注入名义状态 |
| `ProcessConfig1.m` | 仅 GNSS 位置，对应 C++ 样例 |
| `ProcessConfig2.m` | GNSS 速度 |
| `ProcessConfig3.m` | ODO/NHC |
| `function/` | 姿态转换、子午圈曲率、重力 |
| `plot-function/` | 误差、标准差、IMU 误差曲线 |
| `dataset1` `dataset2` `dataset3` | 三组配套数据 |

数据流与 C++ 版相同：机械编排产生名义轨迹，卡尔曼滤波只估计误差，更新后反馈。

## 运行环境

- Matlab R2018b 或更新版本即可运行这些脚本，不需要额外工具箱。
- 在 `KF-GINS-Matlab-main` 目录执行 `kf_gins`。通过修改脚本中的配置函数选择三组数据。
- 无 ROS 依赖，适合 Windows 直接学习方案一。

方案一的底盘部分应从这个仓库读起，而不是从 FAST-LIO 分支读起。补全 `ODONHCUpdate.m` 时，量测应是车体系前向速度以及侧向、垂向零速度，杆臂和安装角与 `ProcessConfig3.m` 保持一致。

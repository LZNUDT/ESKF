# eskf_gnss_imu_localization 架构说明

上游：https://github.com/LimHaeryong/eskf-gnss-imu-localization

ROS2 下的 GNSS/IMU 定位，公式依据 Solà 的 ESKF 笔记。OpenGL 同时显示 GNSS 轨迹和滤波轨迹。许可证 MIT。

## 框架

节点订阅 IMU 与 NMEA/NavSat 位置，完成初始化、预测、GNSS 校正和误差重置，并刷新三维显示。没有底盘速度，也没有雷达点云。它和 `04_imu_gps_localization` 的差别主要是 ROS2 接口和可视化，滤波器阶次相同。

## 运行环境

上游写明：

- Ubuntu 20.04，ROS2 Foxy
- Eigen3、GeographicLib、yaml-cpp、OpenGL
- `nmea_msgs`、`nmea_navsat_driver`
- 数据：UTBM 2019-01-31 无图像 rosbag，并用 `rosbags-convert` 转为 ROS2 bag

在 ROS2 工作空间中 `colcon build`，修改 launch 文件里的 bag 路径后启动 `eskf_gnss_imu_localization.launch.py`。

Foxy 已结束官方支持。若新装系统，优先使用 Ubuntu 22.04 与 ROS2 Humble，并准备处理 Foxy 与 Humble 的接口差异。Windows 上建议 WSL2。

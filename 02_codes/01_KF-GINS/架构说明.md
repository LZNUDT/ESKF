# KF-GINS 架构说明

上游：https://github.com/i2Nav-WHU/KF-GINS

武汉大学 i2Nav 的 GNSS/INS 松组合。算法对应牛小骥、陈起金《惯性导航原理与 GNSS/INS 组合导航》讲义。许可证为 GPL-3.0。

## 框架

程序按时间对齐 IMU 与 GNSS 文件，主循环在 `src/kf_gins.cpp`。每一拍调用 `GIEngine`：

1. `insmech` 用相邻两帧 IMU 增量做双样本机械编排，更新名义位置、速度、姿态。
2. 误差状态协方差按 $\phi$ 角模型传播。
3. 若该拍有 GNSS 位置，则做量测更新。天线杆臂由配置给出。
4. 误差反馈到名义状态，误差均值清零。

21 维误差状态为：

$$
\delta\mathbf{x}=\begin{bmatrix}\delta\mathbf{r}\\\delta\mathbf{v}\\\boldsymbol{\phi}\\\delta\mathbf{b}_g\\\delta\mathbf{b}_a\\\delta\mathbf{s}_g\\\delta\mathbf{s}_a\end{bmatrix}
$$

依次是位置误差、速度误差、姿态误差、陀螺零偏、加计零偏、陀螺标度因数、加计标度因数。速度和位置误差定义在导航系。

## 目录

| 路径 | 作用 |
| --- | --- |
| `KF-GINS-main/src/kf_gins.cpp` | 入口与时间循环 |
| `KF-GINS-main/src/kf-gins/gi_engine.cpp` | 组合导航引擎 |
| `KF-GINS-main/src/kf-gins/insmech.cpp` | 捷联机械编排 |
| `KF-GINS-main/src/fileio/` | IMU 与 GNSS 文本读取 |
| `KF-GINS-main/config/kf-gins.yaml` | 初始状态、IMU 噪声、杆臂、文件路径 |
| `KF-GINS-main/dataset/` | Leador-A15 IMU 与 GNSS-RTK 样例 |
| `KF-GINS-main/scripts/plot_navresult.py` | 结果绘图 |

第三方 Eigen、Abseil、yaml-cpp 随仓库提供，一般不必单独安装。

## 运行环境

- 语言：C++14，构建：CMake。Windows、Linux、macOS 均可。上游建议优先 Linux。
- Windows：Visual Studio 2019 或更新版本，CMake 3.10 以上，可选 Ninja。
- 编译后运行：`kf_gins.exe config/kf-gins.yaml`，工作目录需要能找到配置里的数据路径。
- 样例数据已在 `dataset/`。更完整的多等级 MEMS 数据见 `awesome-gins-datasets`，格式与本程序一致。
- 绘图需要 Python 3、NumPy、Matplotlib。

本仓库没有底盘量测。底盘扩展应在 Matlab 版把 `ODONHCUpdate.m` 补全后，再移植到 `GIEngine`。

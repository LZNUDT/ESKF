# imu_x_fusion 架构说明

上游：https://github.com/cggos/imu_x_fusion

同一松组合问题上并列实现 ESKF、迭代 EKF、UKF（含 JUKF、SVD-UKF）以及 Ceres、g2o、GTSAM 的 MAP 优化，用来对照滤波器与优化器，而不是提供完整车载系统。

## 框架

- IMU 与 GNSS：`imu_gnss_fusion.launch`，示例 bag 为 `utbm_robocar_dataset_20180719_noimage.bag`。话题包括 `/imu/data`、`/fix`。
- IMU 与六自由度里程计：`imu_vo_fusion.launch`，参数 `est` 可选 `ekf`、`ukf`、`map`。六自由度里程计可以是双目视觉里程计的位姿，不是轮速。
- KAIST 文本数据有一个发布节点 `kaist_pub`。

README 中的轮速计和激光雷达仍是未完成项。因此本仓库不作为方案一或方案二的主代码。

解压时 `docs/gnss/img` 与 `docs/sensor/img` 因路径名未能创建，缺少说明文档中的图片。`src` 与 launch 已在目录中。

## 运行环境

- Ubuntu 18.04/20.04，ROS Melodic/Noetic。
- 按所选后端安装 Eigen、Ceres、g2o 或 GTSAM。只跑 ESKF 时可以不装优化库，具体以 `CMakeLists.txt` 的可选编译开关为准。
- UTBM 与 KAIST 数据需单独下载。KAIST Urban 序列体积大，先确认磁盘再下整段。

# FAST-LIO 架构说明

上游：https://github.com/hku-mars/FAST_LIO

香港大学 MaRS 实验室的激光惯性里程计。FAST-LIO 用迭代扩展卡尔曼滤波融合雷达特征与 IMU。当前主线是 FAST-LIO2：原始点直接配准、ikd-Tree 增量地图、外部 IMU，以及在 ARM 板上实时运行。

论文：

- FAST-LIO，RA-L 2021，arXiv:2010.08196
- FAST-LIO2，IEEE T-RO 2022

## 框架

状态定义在 `include/use-ikfom.hpp`，流形工具在 `include/IKFoM_toolkit`。名义上包含姿态 $SO(3)$、位置、速度、陀螺零偏、加计零偏、重力方向 $S^2$，以及雷达与 IMU 外参。

数据流：

1. `IMU_Processing.hpp` 前向传播 IMU，并把扫描内每个点反畸变到扫描结束时刻。
2. `preprocess` 按雷达型号组织点云。特征提取可以关闭。
3. `laserMapping.cpp` 把点到平面残差送入迭代误差状态更新。
4. ikd-Tree 插入新点、删除视场外点。

本目录额外放了一份 ikd-Tree 源码包：`_ikd-Tree_dependency/ikd-Tree-main`。GitHub 源码包不包含子模块，编译前需要把该目录内容放到 FAST-LIO 期望的 `include/ikd-Tree`，或按仓库 README 初始化子模块。`FAST_LIO-main` 里若已带一份 ikd-Tree，以仓库内路径为准，避免两份头文件同时参与编译。

## 运行环境

- Ubuntu 16.04 及以上。18.04 及以上可使用系统自带 PCL 与 Eigen。
- ROS Melodic 或 Noetic。PCL 不低于 1.8，Eigen 不低于 3.3.4。
- Livox 雷达需要 `livox_ros_driver`。Velodyne、Ouster 使用对应 ROS 驱动。
- 内存建议 16 GB，播放大型 rosbag 时 32 GB 更稳妥。树莓派 4B 8 GB 可跑低线数雷达，不适合同时录制和建图。

IMU 与雷达必须硬件同步，点云需要逐点时间戳。缺少 `time` 字段时，运动补偿会失效。

本仓库没有 GNSS，也没有轮速。方案二不要只编译这一份。

# imu_gps_localization 架构说明

上游：https://github.com/ydsf16/imu_gps_localization

按照 Solà《Quaternion kinematics for the error-state Kalman filter》实现的 IMU 与 GPS 松组合，ROS1 包装。作者说明文章见 https://zhuanlan.zhihu.com/p/94030638 。配套数据是 UTBM Robocar，https://epan-utbm.github.io/utbm_robocar_dataset/ 。

## 框架

| 路径 | 作用 |
| --- | --- |
| `imu_gps_localizer/` | 与 ROS 解耦的预测、量测更新、误差重置 |
| `ros_wrapper/` | 订阅 IMU 与 GPS，发布轨迹 |

预测用 IMU 角速度和比力积分名义位姿与速度，协方差在误差状态上传播。GPS 只修正位置。姿态误差为三维旋转向量，更新后乘到名义四元数上并重置。没有 GNSS 速度、杆臂、地球模型和底盘约束，因此长距离车载精度不如 KF-GINS。

## 运行环境

- Ubuntu 18.04 或 20.04，ROS Melodic 或 Noetic，Eigen3，C++14。
- 工作空间：`catkin_make` 后 `source devel/setup.bash`。
- 需要自行下载 UTBM rosbag。无图像版本体积更小，足够跑本程序。

Windows 原生 ROS1 不建议使用。若只有 Windows，用 WSL2 Ubuntu 20.04。
